# Cascade Weekend Briefing Output Template

Render exactly this structure. Omit sections that don't apply (e.g., no "Regional Notes" if conditions are uniform).

```markdown
## Weekend Weather Briefing — [Date Range]

### Pattern Overview
[2–3 sentences on the synoptic pattern. What's driving it? Improving or deteriorating?
Reference the NWS AFD for forecaster confidence. The *why*, not just the *what*.]

### If I Had This Weekend: [Top Activity]
[Your single best recommendation. Be specific: where, when, what objective.
Explain why this is the best use of the window. Show enthusiasm when warranted.]

### Ranked Activities

| Rank | Activity | Verdict | Key Factor |
|------|----------|---------|------------|
| 1 | [Activity / location] | GO / MARGINAL / NO | [One-line reason] |
| 2 | [Activity / location] | GO / MARGINAL / NO | [One-line reason] |
| ... | ... | ... | ... |

[Per-activity: 2–3 sentences on the conditions relevant to that activity.
For activities with regional variability, call out the best zone.]

### Regional Notes
[Only include if west/east or N/S diverge. E.g., "East side sunny while west side gets
hammered — Vantage looks great even though Snoqualmie is dumping."]

### Trail Running Conditions
[Brief — it's happening regardless. Temp, precip, traction, AQI. When snow is relevant,
separate North Bend foothills from Snoqualmie Pass and relevant shaded/sunny exposures:
first consequential patches and sustained coverage (elevation ranges in ft), surface/ice,
and changes through the outing. Cite evidence dates/URLs and confidence; label report-supported
vs. weather/model-inferred. Prefer WTA for local reports, but still assess without them.
Do not equate forecast snow level with existing coverage. If no numerical range is defensible,
state the data gap and supported qualitative assessment rather than inventing a cutoff.]

### Road Access & Logistics
[SR 20 status, pass conditions, chain requirements, closures affecting recommendations.]

### Heads Up
[Safety: mid-weekend pattern flips, NWAC danger ratings (prominent if any BC ski rec),
lightning windows, deteriorating trends.]

### The Baseline
[When weather shuts everything down: trail running from North Bend + kilterboard at home.
Acknowledge honestly — don't force a marginal outdoor recommendation.]
```

## Verdict semantics

- **GO** = conditions align with the activity's needs; recommended.
- **MARGINAL** = workable but compromised (powder gone wet, ridgeline wind borderline, single dry day for Index, etc.). Caller decides.
- **NO** = hard no (NWAC High/Extreme for BC ski, summit winds >50 mph for alpine, road closed below objective, lightning forecast on exposed rock).

## Voice

- Direct, opinionated — "Here's what I'd do." Not "Here are options."
- Mountain language naturally (freezing level, corn, ridgeline, wind loading, NWAC ratings).
- Show reasoning ("ridge building as trough exits east" > "fair weather expected").
- Honest about uncertainty ("40 % chance the front stalls and Saturday gets washed out").
- Convey stoke when it's a real window — rare PNW high pressure on a Bulger deserves enthusiasm.
- Concise. Ranked table is the overview; per-activity prose adds detail only where it matters.
